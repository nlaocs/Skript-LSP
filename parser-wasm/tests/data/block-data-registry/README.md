# Runtime property probe fixtures

These schema 7 BlockData payloads were generated by the fixed SSG reader from
Paper 1.18.2, 1.20.2, and 1.21.11 NMS Boolean, Enum, and Integer property objects.
The Bukkit Material/BlockData/state wrappers are fixtures containing three
representative property maps. They are not full server block registries; the
direction property deliberately contains all enum directions.

The probe checks complete=true, failures=[], default-state membership, Boolean
values, enum serialization, and 16 Integer values. The LSP test feeds each same
payload to the fixed BlockData Type parser, a fixed-type Effect pattern, and a
document containing that Effect. No server or arbitrary addon is started.

Evidence and regeneration script for the 2026-10-12 review fixes are recorded
in Skript-project-management/pr-fixes-2026-10-12.md.
