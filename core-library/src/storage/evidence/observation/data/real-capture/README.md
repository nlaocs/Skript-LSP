# Registry observation fixtures

Captured from two isolated Paper 1.21.11 / Skript 2.15.4 environments on 2026-10-28,
with SSG only or SSG plus skript-reflect 2.6.3. No clients or gameplay.
Manifest files retain their exact captured bytes; Type and EventValue rows are
field projections preserving order, absence, values and capture-local identities.
The provenance ledger records exact original/exported hashes and fields.

These are observation fixtures, not authenticated native-event origins or
continuous mutation epochs. Hidden getter implementations remain unknown. The
Rust unit tests use self-authored SourceIdentity integrity keys and must not
claim those keys are host digests of this projected fixture subset. Production
read-path tests obtain source identity from Catalog. No private access material,
credentials, server settings, or captured world data are included.
